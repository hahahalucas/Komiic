# Komiic for iOS 0.9.0

基于 v3.0 升级的原生 SwiftUI 漫画客户端，当前版本 **0.9.0（build 9）**，支持 iPhone / iPad、iOS 17 及以上。使用 Apple 系统框架，无第三方运行时依赖。iOS 26 使用系统 Liquid Glass 导航及阅读控制条，旧系统保留兼容外观。

## 本次更新

- 竖屏采用整话长条，同一话内所有图片随双指手势同步缩放；横屏自动切换左右双页，两页作为一个整体缩放。最小原比例，最高 5 倍。
- 放大长条后仍可上下连续阅读，横屏放大后拖动查看当前双页；原图只在可见区域及附近解码，保留整话预加载和离线阅读。
- 首页及筛选结果、账号资料、收藏、书柜、屏蔽和最近阅读加入跨重启快照。再次打开先显示缓存，不自动清空重载；下拉刷新获取最新数据。
- 登录会话保存到系统 Keychain，启动时恢复并按需续期；合并同时发生的官网会话同步。账号/普通/H 分区隔离缓存，退出登录清除对应账号快照和凭据。
- 阅读顶部控制条位于灵动岛/刘海安全区域下方 8 点，阅读图片继续铺满屏幕，底部控制条保留原位置。

## 0.8.0 已有功能

- 阅读图片支持双指放大、拖动查看；双指收拢最多还原至原始比例，不会缩得更小，也没有缩放回弹。支持滚动、翻页及 iPad 双页阅读。
- 放大时拖动只移动图片，避免误翻页或误触章节末尾跳转；通过控制条换页、换话或旋转屏幕时还原比例。
- 修复点击书柜内漫画后仍显示书柜、返回才看到漫画详情的问题。书柜和漫画使用同一条导航路径，返回顺序为漫画详情 → 书柜 → 书柜列表。
- 最近阅读点击封面进入漫画主页，由主页「继续阅读」恢复上次章节和页码；保留原有进度显示和内容警告规则。

## 0.7.0 已有功能

- 阅读图片票据与首页、搜索等官网接口共用连接池，减少重复建立连接；漫画详情与章节目录合并为一次请求。
- 封面缩略图与漫画原图在后台解码，已解码封面继续复用；页面缓存读写和图片校验移出主线程。漫画原图保留完整分辨率和图片方向。
- 保存每张图片时只更新本次增加的缓存字节，不再反复扫描整个缓存目录；缓存清理仍阻止旧请求重新写回。
- 整话预加载随当前阅读位置调整后续请求的顺序，跳页后优先新位置；最多同时预加载 3 页，已完成及正在加载的页面继续复用。
- 遇到登录失效、图片额度不足或限流时停止剩余后台预加载，避免继续发送无效请求；普通单页失败保留原有跳过与重试行为。

## 0.6.0 已有功能

- 打开一话后自动预加载整话图片，优先当前阅读位置及后续页；首屏先显示，其余图片在后台加载，不依赖翻页或滚动触发。
- 最多同时预加载 3 页，整话保留压缩图片缓存，只解码需要显示的页面，适用于滚动、翻页及 iPad 双页阅读。
- 预加载、正在阅读的页面及离线下载共用同一图片请求，已缓存的页面不重复下载；单页失败不阻塞后续页面，仍可单独重试。
- 切换章节或退出阅读时取消预加载；选择「看完后」清理缓存时，未完成的旧请求不会重新创建已清理的缓存。
- 阅读器始终隐藏时间、电量、Wi-Fi 等系统状态栏，点击画面只切换阅读控制条，按键位置保持原样。
- 删除底部控制条的在线阅读/自动缓存提示行。

## 0.5.0 已有功能

- 登录后书柜及屏蔽列表从官网同步，书柜创建、改名、删除、移入/移出漫画、屏蔽/解除均写回官网；失败操作按账号及分区持久化等待重试。
- 首页和账号资料在首次进入后保留；切换标签、返回页面、回到前台不会重新读取。下拉刷新主动获取官网最新数据。
- 封面内存/磁盘缓存、重复图片请求合并、适量预载相邻页，减少重复连接与图片解码。
- 移除全局“未能完成操作”弹窗及账号页“重新读取”按钮，错误在对应页面内显示。
- 最近阅读采用每行三本的封面网格，保留继续阅读位置和进度。
- iPad 横屏自动双页：向右阅读左 1 右 2，向左阅读左 2 右 1，按两页翻动；图片保持原比例贴合中缝。
- 内容警告封面首次点击解除模糊，再次点击进入；完全隐藏的漫画继续隐藏。
- 章节末尾继续上拉进入下一话；最后一话继续上拉返回目录。底部中间显示当前话数，点击选择附近五话。
- 保留普通/H 漫画分区、官网会话、搜索、作者作品、真实已读目录、阅读书签和离线下载。

## 打开和运行

1. 在 Mac 使用 **Xcode 26 或更新版本**打开 Komiic.xcodeproj。
2. 选择 Komiic scheme 和 iPhone / iPad 模拟器运行。
3. 真机安装需在 Signing & Capabilities 中选择自己的开发团队，并替换示例 Bundle Identifier。
4. 在底部“账号”中打开官方网页登录。App 使用官网 Cookie 会话，不直接保存账号密码。

工程采用同步文件夹分组，Komiic/ 和 KomiicTests/ 下新增 Swift 文件自动加入对应 target。

## 保留的 v3 功能

首页五页滑动切换、下拉刷新、分页及内容分级；作者全部作品；漫画详情与官方分级说明；按卷/话分组的四列目录、真实已读章节折叠、最后章节/页码恢复；纵向/横向阅读；书签、书柜、离线下载与断网阅读。

通用设定页面已移除。阅读器内仍保留阅读方式、柔和显示和墨水模式等直接影响阅读的操作。已有设置继续可读取。

## 官网资料与本机资料

普通/H 漫画的官网收藏和历史按官网域名获取。登录后以当前账号的官网资料为准，新增操作写回官网；官网取消收藏或删除历史后，App 刷新也会移除。未登录时使用独立本机喜爱和阅读记录。退出登录清除官网快照并恢复本机存档；待重试操作不会发送给另一个账号。

未登录时书柜与屏蔽保存在本机；登录后以官网快照为准，退出登录恢复独立本机资料。账号页书柜卡片进入已同步书柜。阅读位置书签与离线文件保存在本机，官网书签及追踪书柜保留官网入口。账号资料修改保留官网入口。

本机存档位于 Application Support/Komiic/library.json，采用原子写入，无法读取的原始存档会保留恢复副本。永久下载位于 Documents/KomiicOffline/，在线缓存位于 Caches/KomiicPages/。清理在线缓存不会删除永久下载。

图片继续使用官网 getImageTicket / X-Image-Ticket 流程，遵守账号额度及限流；图片 CDN 请求不携带账号 Cookie。

## 验证与构建

0.9.0 已增加整话/双页缩放、缓存重启恢复、账号切换及会话续期回归测试，共 118 项/设备。Windows 工程结构与 Swift 语法检查通过；iPhone/iPad XCTest、设备 Release 编译和本版 IPA 校验待云端执行，状态见[验证记录](docs/Verification.md)。

0.8.0 历史构建与下载链接保留在[构建说明](docs/IPA.md)。本版安装包将在本次构建及校验通过后提供。

本地环境为 Windows，可执行工程结构和 Swift 语法检查：

```sh
python -m pip install --target .validation-packages -r scripts/requirements-validation.txt
python scripts/verify_project.py --require-swift-parser
git diff --check
```

2026-11-22 已实际验证两个官网域名的四类首页接口，八次请求均返回 HTTP 200，且内容类型分别为 REGULAR / H_MANGA，见 [0.4.0 接口记录](docs/v0.4.0-api.json)。登录后的资料读取、偏好与同步写入仍需真实账号验收。

Xcode 编译、XCTest、模拟器界面及真机验证需在 Mac 完成；本地语法检查不能代替这些步骤。0.9.0 的云端编译、测试及 IPA 状态见 [验证记录](docs/Verification.md)，构建及签名方法见 [IPA 说明](docs/IPA.md)。

```sh
bash scripts/build_ipa.sh --unsigned
```

无签名 IPA 安装前需要使用自己的证书签名。历史 3.0、2.0 和 0.1.0 构建记录不代表本次版本。
